# MNL INDUSTRIE — MNL WORLD
Site multi-pages premium pour le groupe technologique virtuel MNL Industrie.

## Fichiers
- `index.html` : accueil cinématique
- `products.html` : catalogue interactif (recherche, filtre, tri, fiches)
- `divisions.html` : présentation des 10 divisions
- `about.html` : vision et écosystème
- `style.css`, `app.js`, `data.js` : styles, interactions et catalogue
- `assets/` : rendus visuels de concepts originaux et icône
- `manifest.webmanifest`, `sw.js` : installation PWA et cache hors ligne

## Lancer sur Android
Extraire le ZIP et ouvrir `index.html` dans un navigateur pour une prévisualisation locale. Les fonctions PWA et le mode hors ligne sont activés après publication sur un hébergement HTTPS.

## Publier gratuitement sur GitHub Pages
1. Créer un dépôt GitHub public nommé `mnl-industrie`.
2. Importer tout le contenu de ce dossier (pas le dossier parent lui-même) à la racine du dépôt.
3. Ouvrir Settings → Pages.
4. Choisir Deploy from a branch, branche `main`, dossier `/ (root)`, puis Save.
5. Attendre la publication. L'adresse prendra la forme `https://TON-PSEUDO.github.io/mnl-industrie/`.

## Transparence
MNL Industrie est présenté ici comme un univers de marque virtuel. Tous les produits du catalogue sont des concepts fictifs illustrés par des rendus visuels. Aucun n'est annoncé comme fabriqué, certifié, disponible à l'achat ou techniquement validé.
Le site est statique : il ne comprend pas encore de comptes utilisateurs, de base de données cloud, de paiement, de panneau d'administration ni de synchronisation entre appareils.
